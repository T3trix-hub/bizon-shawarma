# 🌯 БІЗОН — сайт шаурмечной

Многостраничный сайт для шаурмечной **БІЗОН** в Минске (ул. Сергея Есенина, 38): меню с фото и ценами, контакты, карта, галерея. Светлая и тёмная тема, адаптивная вёрстка, плавные анимации. Чистые HTML, CSS и JavaScript, без сборки и npm.

## Страницы

| Страница | Что внутри |
|---|---|
| `index.html` | Главная: первый экран, блок «Из меню», преимущества, призыв позвонить |
| `menu.html` | Полное меню по категориям: шаурма, бургеры, закуски, блины, сеты, напитки |
| `about.html` | О заведении и галерея |
| `contacts.html` | Адрес, часы работы, телефоны, Instagram, карта Яндекса |

## Возможности

- Меню рисуется из одного файла данных, поэтому цены и позиции правятся в одном месте.
- Карточка блюда: фото, состав, размеры, вес и цена. Если фото нет, показывается значок категории.
- Светлая и тёмная тема. Сайт берёт тему системы и запоминает выбор посетителя.
- Плавное появление блоков при прокрутке и мягкие переходы между страницами. Если в системе отключена анимация, она не включается.
- Адаптив под телефон: меню-бургер, учёт выреза и верхней панели iPhone.
- Шапка, подвал, контакты и меню собираются скриптом, поэтому не дублируются на каждой странице.

## Структура

```
index.html  menu.html  about.html  contacts.html
css/style.css          — стили и обе темы
js/data.js             — контакты и всё меню (меняется чаще всего)
js/main.js             — шапка, подвал, меню, тема, анимации
images/                — фото заведения и логотип
images/menu/           — фото блюд
favicon*.png, favicon.ico
```

## Как поменять контакты и меню

Всё в `js/data.js`:

- `SITE` — адрес, часы работы, телефоны, Instagram, ссылка на Яндекс Карты.
- `MENU` — категории и позиции. Позиция: `[id, название, описание, размеры]`.
- `FEATURED` — какие блюда показывать на главной в блоке «Из меню».
- `GALLERY` — фото для страницы «О нас».

## Как добавить фото блюда

1. Возьми `id` позиции из `js/data.js`, например `firmennaya`.
2. Положи фото в `images/menu/` и назови `firmennaya.jpg`.

Больше ничего менять не нужно. Формат только `.jpg`, имя в нижнем регистре, лучше горизонтальное фото 4:3 до 200–300 КБ. На GitHub Pages регистр имени файла важен.

## Публикация на GitHub Pages

1. Залей содержимое папки в корень репозитория (`index.html` лежит в корне).
2. В репозитории: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
3. Через минуту-две сайт откроется по адресу `https://<пользователь>.github.io/<репозиторий>/`.

Локально сайт можно просто открыть, дважды кликнув по `index.html`.

## Внешние сервисы

Единственные внешние подключения: шрифты Google Fonts (Unbounded и Manrope) и карта Яндекса на странице контактов. Без интернета сайт откроется, но со стандартными шрифтами и без карты.
